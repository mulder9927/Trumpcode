## Installing TrumpLang

It's very simple. Incredibly simple. People tell me, "Sir, I've never seen an installation this clean." And I say, "I know. We built it that way."

### Step 1 — Get the `trump` binary

```bash
git clone https://github.com/[your-org]/TrumpCode.git
cd TrumpCode
./configure --prefix=/usr/local
make trump
sudo make install
```

That's it. **Done.** You now have `trump` installed. Nobody installs faster than us.

> **Note:** You will need `gcc`, `make`, and `zlib` development headers. These are the best tools. Very standard. Even the fake news media uses them.

### Step 2 — Write a `.trump` file

Open any text editor — even the ones made by the radical left — and write your program. Save it as `myprogram.trump`.

### Step 3 — Run it

```bash
trump myprogram.trump
```

That's it. It runs. **Beautifully.**
